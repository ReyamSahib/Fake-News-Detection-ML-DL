# Fake News Detection using Machine Learning and Deep Learning


This project compares machine learning and deep learning techniques for classifying news articles as fake or real.

## Team Contribution

This project was completed collaboratively by a two-member team as part of an Artificial Intelligence course project.

My contributions included:
- Data preprocessing 
- Machine learning model development, evaluation, and research
- Performance analysis and result comparison

Each team member contributed to the design, implementation, testing, and documentation of the project.

## Models Implemented
- Multinomial Naive Bayes
- Random Forest
- Convolutional Neural Network (CNN)

## Data Processing
- Text Cleaning
- Stop Word Removal
- Stemming
- Lemmatization
- Bag of Words
- TF-IDF Vectorization

## Libraries Used
- Python
- Pandas
- NumPy
- NLTK
- Scikit-Learn
- TensorFlow / Keras
- Matplotlib
- Seaborn

## Evaluation Metrics
- Accuracy
- Classification Report
- Confusion Matrix

## Results
The models were evaluated and compared using multiple performance metrics to identify the most effective approach for fake news detection.

## Dataset Notice

The datasets used in this project (Fake.csv and True.csv) are not included in this repository.

They have been omitted to:
- Reduce repository size
- Respect dataset licensing and distribution requirements
- Keep the repository focused on the implementation and methodology

To run the notebook, place the required dataset files in the project directory before execution.
